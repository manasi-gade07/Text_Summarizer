# 🚀 Fast AI Text Summarizer

A web-based application that allows users to input text and receive a concise AI-generated summary instantly. Built with **Flask** for the backend and modern **HTML, CSS, and JavaScript** for the frontend.

---

## Features

- 📝 Input large text and get a summarized version instantly.
- 📋 Copy the generated summary to the clipboard with a single click.
- 🌈 Modern and responsive UI with gradient background and smooth interactions.
- ⚡ Fast and easy-to-use.
